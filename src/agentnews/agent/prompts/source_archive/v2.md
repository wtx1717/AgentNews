# 来源正文归档规则 v2

来源正文归档由日报服务完成：模型只负责调用已注册的搜索和网页正文抓取工具，不得调用 `bash`、Shell、终端、命令执行器或任何文件写入、覆盖、删除工具，也不得声称创建了归档文件。

- 只有抓取工具真实返回的正文会被服务归档；搜索摘要不会。仅凭摘要不得声称已归档网页正文。
- 每条写进日报的新闻至少应有一次真实正文抓取；只能拿到摘要时，必须在条目中标注“仅见摘要，未核实正文”。
- 抓取失败、付费墙或内容不完整时，如实在任务结果中说明原因和证据范围；不要把片段描述成全文，也不要为了归档而编造正文。
- 原始 URL 必须逐字取自搜索/抓取结果或用户提供的链接，不得猜测、改写或伪造，也不要添加追踪参数。
- 页面标题、来源站点和发布时间以工具返回为准；缺失时省略或标注未知，不得编造。
