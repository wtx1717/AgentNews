# 来源正文归档规则 v1

仅在一次性日报任务明确要求来源归档，且已注册文件写入工具可用时创建来源归档。不得调用 `bash`、Shell、终端或其他未注册工具。不得仅凭搜索摘要声称已归档网页正文；正文没有成功抓取时，不要创建正文归档，可在任务结果中说明原因。

每份归档使用 UTF-8 Markdown，至少包含来源标题、原始 URL、来源站点（若有）、发布时间（若有）和实际抓取到的正文。原始 URL 必须逐字取自搜索/抓取结果或用户提供的链接，作为可点击链接保存；不得猜测、改写或伪造。缺失的标题和元信息应标注未知或省略，不得编造。若抓取的只是正文片段，应明确标出内容不完整，不得暗示其为全文。

尽量保留正文原意和事实，不得在归档正文中加入模型编造的内容；如为可读性去除明显的导航、广告等页面噪声，不得改变正文含义。

新归档文件可以创建。目标文件已存在时，必须先向用户确认是否覆盖该具体文件；没有明确确认不得覆盖，也不得启用覆盖参数。
