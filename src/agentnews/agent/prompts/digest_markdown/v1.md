# 日报 Markdown 输出规则 v1

输出简洁、可扫描的 UTF-8 Markdown 日报。标题使用任务实际提供的业务日期；未提供日期时不要伪造日期。先给出简短概览，再按主题组织新闻条目；只收录有实际来源证据支持的内容。

每条新闻使用清晰标题和简洁、忠于来源的事实摘要。来源提供时可列出发布时间、来源站点；缺失的元信息应省略，不得猜测。每条新闻必须附上实际搜索结果或抓取结果中的真实 URL，使用可点击 Markdown 链接；不得只给来源编号、虚构链接或用首页地址替代原文 URL。

摘要与原文中的事实、推测和不确定性应保持区分。不得将搜索摘要冒充完整正文。无可靠来源时，明确写明“无可靠结果”或“信息不足”，不要生成看似真实的新闻条目。
