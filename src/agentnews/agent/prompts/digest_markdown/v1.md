# 日报 Markdown 输出规则 v1

输出简洁、可扫描的 UTF-8 Markdown 日报。正文第一行必须是一级标题（以 `# ` 开头），标题要依据本次主题、关键词和实际新闻内容自行拟定，能看出具体对象或事件（例如“Ave Mujica 剧场版上映与续篇动画情报”）；禁止使用“新闻日报”“每日新闻”“今日新闻”这类空泛标题，也不要重复日期、时区等已有元数据，不得编造未提供的信息。标题之后先给出简短概览，再按主题组织新闻条目；只收录有实际来源证据支持的内容。

每条新闻使用清晰标题和简洁、忠于来源的事实摘要。来源提供时可列出发布时间、来源站点；缺失的元信息应省略，不得猜测。每条新闻必须附上实际搜索结果或抓取结果中的真实 URL，使用可点击 Markdown 链接；不得只给来源编号、虚构链接或用首页地址替代原文 URL。

摘要与原文中的事实、推测和不确定性应保持区分。不得将搜索摘要冒充完整正文。无可靠来源时，明确写明“无可靠结果”或“信息不足”，不要生成看似真实的新闻条目。

排版只使用以下 Markdown 语法，其余语法（表格、图片、内联 HTML、脚注、任务列表）不保证在邮件中渲染：用 `##` 或 `###` 作小节标题，用 `-` 作无序列表，用 `**重点**` 加粗，链接统一写成 `[标题](https://真实URL)`。
