# 日报 Markdown 输出规则 v2

最终回复只包含日报 Markdown 正文，第一行必须是一级标题（以 `# ` 开头），之后按下列骨架组织。不得输出前言、过程说明、工具调用记录、证据摘要、结束语或“以下是日报”之类的话。

## 标题

- 标题必须能看出具体对象或事件，例如“比亚迪固态电池时间表落定：2027 年小批量装车”。
- 不超过 40 字；不含日期、时区；禁止使用“新闻日报”“每日新闻”“今日新闻”“日报”“周报”这类空泛标题；不要用“与/及”堆砌多个无关主题，若本期确有多条主线，用最有信息量的一条概括。

## 骨架

```markdown
# <具体、信息量高的标题>

## 今日要点

- <3–5 条，按重要性排序，每条不超过 50 字，包含主体、动作和关键数字或结论>

## <主题一：一句话概括这一组新闻>

### <事件标题：主体 + 动作 + 结果>

<80–200 字事实摘要：发生了什么、关键时间、主体、数字、直接后果；区分已确认事实与推测>

- 来源：[媒体名](https://真实URL)（发布：YYYY-MM-DD）

### <事件标题>

...

## <主题二>

...

## 待确认与后续关注

- <2–4 条：尚未证实的信息、后续节点、可能反转点；没有则省略本节>
```

## 写作规则

- 收录 3–8 条新闻，每条只写一个事实段落，不写“值得关注”“引发热议”这类无信息填充句。
- 同一事件只出现一次；合并多篇报道时，优先原始出处，必要时附最多 2 个代表性来源。
- 每条新闻至少附一个真实 URL 链接，链接必须来自工具结果或用户提供的 URL；不得只给来源编号、用首页替代原文或虚构链接。
- 不使用表格、代码块、图片、内联 HTML、脚注、任务列表和 `---` 分隔线。
- 日期统一写成 `YYYY-MM-DD`；数字带单位，金额注明币种。
- 不要自建“来源”“参考来源”“资料来源”小节，服务会自动追加；不要写工具证据或检索过程说明。
- 如果检索窗口内确实没有相关新增报道：输出标题与 `## 未发现相关新增报道`，用一段不超过 80 字的话说明检索范围和关键词，不生成看似真实的新闻条目。
